## Getting Started

### Prerequisites

- **JDK** 8 or higher
- **Apache NetBeans** IDE
- **Database server** (<!-- TODO: e.g. MySQL -->) and its JDBC driver

### Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/ahmedhussienaboomar-tech/Hospital-Management-System.git
   ```

2. **Create the database**
   Open the `2_database_code` folder and run the SQL script(s) in your database server.

3. **Open the project in NetBeans**
   `File` → `Open Project` → select the project inside `3_NetBeans_code`.

4. **Configure the database connection**
   <!-- TODO: Mention the file/class where the connection URL, username, and password are set -->
   Update the URL, username, and password to match your database.

5. **Run the application**
   Right-click the project → `Run`.
